# Агрегатор данных из access-логов веб-сервера Apache

Студенческий проект по сбору, фильтрации и хранению логов веб-сервера Apache в базе данных SQLite с использованием Python (Flask).

## Инструкция по запуску и использованию

1. Установите веб-фреймворк Flask (если еще не установлен):
   pip install flask

2. Запустите скрипт парсера логов (он автоматически создаст папку logs, тестовый файл access.log и базу данных):
   python parser.py

3. Запустите веб-приложение:
   python app.py

4. Откройте в браузере адрес: http://127.0.0.1:5000

5. Авторизуйтесь в системе:
   * Логин: admin
   * Пароль: admin123
